## 4. 效果实验边界

本地单元/契约测试证明确定性选择、能力门控、授权、错误策略、幂等、Outcome 校准和敏感信息边界；它们不等同于真实 Provider 效果 A/B。正式启用前必须使用同一 Catalog Release、同一 Credential 集合和固定 200 项 Golden Task（C0–C3 各 50 项）完成 Anchor、smart_single、固定 Ensemble、selective_ensemble 四组实验，并记录 manifest SHA-256、通过率、Review blocker/high、平均修复轮次、P50/P95 latency 和 token usage。

发布判定：smart_single 相对 Anchor 通过率下降不超过 1 个百分点；selective_ensemble 在 C3/失败恢复样本提升至少 5 个百分点或平均修复轮次下降至少 20%；工具副作用重复数为 0；single 路由 P95 小于 20ms。未完成真实 Provider/Golden Task 实验前，不得把本报告中的自动化通过结果表述为模型质量提升。
