## Scripts 工具

### check-contract-drift.sh
**用途**: 检查源 Schema 与生成代码之间的合约漂移。

**工作流程**:
1. 保存当前生成的文件状态
2. 重新生成所有合约代码
3. 对比差异
4. 恢复原始文件
5. 报告差异或确认无漂移

**使用方法**:
```bash
./scripts/check-contract-drift.sh
```

### generate-contracts.sh
**用途**: 从 JSON Schema 源生成所有合约类型（TypeScript、Pydantic、Rust、OpenAPI）。

**生成目标**:
- TypeScript types (RPC) → `apps/desktop/src/generated/rpc/`
- Pydantic models (Sidecar) → `sidecar/ibreeze/generated/`
- Rust types (Desktop Core) → `apps/desktop-core/src/generated/`
- TypeScript API client (Admin Web) → `apps/admin-web/src/generated/openapi/`
- OpenAPI spec → `packages/contracts/openapi/`

**使用方法**:
```bash
./scripts/generate-contracts.sh
```

### schema-gen-rust (Rust 工具)
**用途**: 从 JSON Schema 生成 Rust 类型定义。

**特性**:
- 支持枚举、结构体、数组、原生类型
- 自动处理 `$ref` 引用
- 生成带有 `serde` 派生的代码
- 支持 `uuid`、`chrono` 等常用类型

## Agent Runtime Gateway

### transport.py - 模型传输适配器
**用途**: 提供不同模型提供商的 API 调用适配器。

**支持的提供商**:
- `OpenAITransport`: OpenAI 及兼容 API
- `AnthropicTransport`: Anthropic Claude API

**工厂函数**:
```python
transport = create_transport("openai", api_key="sk-xxx", model="gpt-4o")
```

### cli.py - CLI 适配器
**用途**: 为不同 CLI 工具提供统一的探针和调用接口。

**支持的适配器**:
- `CodexCliAdapter`: OpenAI Codex CLI
- `ClaudeCodeAdapter`: Anthropic Claude Code CLI
- `OpenCodeAdapter`: OpenCode CLI

**探针检查**:
```python
probe = await probe_agent("codex_cli")
if probe.available:
    print(f"Version: {probe.version}")
```

### model_loop.py 增强
**新增功能**:
- `ToolPermission`: 工具权限控制（Allow/Deny/Ask）
- `Checkpoint`: 检查点管理，支持回滚
- `PermissionChecker`: 权限检查器
- `Verifier`: 输出验证器

### events/__init__.py - 事件系统
**用途**: 提供标准事件发布/订阅机制。

**支持的事件类型**:
- 运行生命周期: `run.started`, `run.completed`, `run.failed`, `run.cancelled`
- 工具调用: `tool.requested`, `tool.completed`, `tool.failed`, `tool.denied`
- 模型输出: `model.thinking`, `model.output`
- 检查点: `checkpoint.created`
- 验证: `verification.passed`, `verification.failed`
- 权限: `permission.granted`, `permission.denied`

**使用示例**:
```python
publisher = EventPublisher()
publisher.subscribe(EventType.RUN_STARTED, my_callback)
envelope = publisher.publish(
    EventType.RUN_STARTED,
    run_id="run-123",
    company_id="company-1",
    employee_id="emp-1",
    payload={"task": "analyze code"}
)
```

## Workspace & Artifact

### artifacts/service.py - CAS 存储
**用途**: 基于内容寻址的不可变工件存储。

**特性**:
- SHA256 去重
- 版本链追踪（supersedes chain）
- 事务性写入

**使用示例**:
```python
result = await create_artifact(
    db,
    company_id="company-1",
    company_task_id="task-123",
    artifact_type="code",
    content=b"...",
    filename="main.py",
    mime_type="text/x-python",
    created_by_employee_id="emp-1"
)
```

### review/service.py - 审查服务
**用途**: 工件审查分配、报告和问题跟踪。

**功能**:
- `assign_reviewer`: 分配审查者（自动拒绝贡献者）
- `submit_review_report`: 提交审查报告
- `create_review_issue`: 创建审查问题
- `resolve_review_issue`: 解决审查问题

### approvals/service.py - 人工审批
**用途**: 外部写入和不确定恢复的人工审批服务。

**功能**:
- `request_external_write_approval`: 请求外部写入审批
- `request_uncertain_recovery_approval`: 请求不确定恢复审批
- `resolve_approval`: 决定审批请求
- `expire_stale_approvals`: 过期处理

## Orchestration

### availability_checker.py - 可用性检查
**用途**: 执行前的 7 项资源可用性检查。

**检查项**:
1. Agent CLI 可执行文件可用
2. 模型提供商可访问
3. 特定模型可用
4. 所需技能已安装
5. 工作区可用
6. 并发槽位可用
7. 系统健康

**使用示例**:
```python
report = await run_availability_checks(
    db,
    company_id="company-1",
    adapter_type="codex_cli",
    provider="openai",
    model="gpt-4o"
)
if not report.all_passed:
    for check in report.checks:
        if check.status == CheckStatus.FAIL:
            print(f"Failed: {check.check_name} - {check.message}")
```

### collaboration.py - 协作策略
**用途**: 多员工任务执行的协作策略。

**支持的策略**:
- `INDEPENDENT`: 独立执行，每个员工获得完整输入
- `PARALLEL_WITH_MERGE`: 并行执行，结束时合并
- `PRIMARY_WITH_PEER_REVIEW`: 主要执行者 + 同行审查
- `SEQUENTIAL_REFINEMENT`: 顺序精炼链

### workflow_templates.py - 工作流模板
**用途**: 常见任务类型的预定义工作流模板。

**内置模板**:
- `software_requirement_delivery`: 软件需求交付标准工作流

**工作流阶段**:
1. 分析 (Analysis)
2. 架构 (Architecture)
3. 开发 (Development)
4. 测试 (Testing)
5. 首次集成测试 (First Test)
6. 修复 (Fixing)
7. 最终测试 (Final Test)
8. GM 审查 (GM Review)

**使用示例**:
```python
template = get_workflow_template("software_requirement_delivery")
next_steps = get_next_steps(template, completed_phases={WorkflowPhase.ANALYSIS})
```

## Backup Service

### backup/service.py
**用途**: 数据库备份、恢复、保留策略管理。

**功能**:
- `create_backup`: 创建带清单的备份
- `restore_backup`: 从备份恢复，支持清单验证
- `list_backups`: 列出所有可用备份
- `apply_retention_policy`: 应用保留策略（每日/每周）
- `delete_backup`: 删除特定备份

**使用示例**:
```python
manifest = await create_backup(
    db_path=Path("~/.ibreeze/data.db").expanduser(),
    backup_dir=Path("~/.ibreeze/backups").expanduser()
)

result = await restore_backup(
    backup_dir=Path("~/.ibreeze/backups").expanduser(),
    backup_id="backup-123",
    target_db_path=Path("~/.ibreeze/data.db").expanduser()
)
```
